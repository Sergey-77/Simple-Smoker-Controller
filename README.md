**Simple controller for Charbroil Simple Smoker based on Arduino Nano ESP32 or NodeMCU 1.0 controller.**

My smoker had random issues with connecting to the phone app that's how this project is started. The original controller is using PWM signal with preset duty cycle to control the smoker temperature. I recreated it in the code and also added option to add thermocouple for better temperature control with PID.
